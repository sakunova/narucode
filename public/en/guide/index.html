GETTING STARTED / ENGLISH

Start with Strudel

A short introduction to Strudel, a live coding environment that runs entirely in your browser. No install, no cost.

01 What Strudel is

Strudel is a music programming environment that runs in the browser. Open strudel.cc and it's ready. Nothing to download, nothing to pay.

It's developed as the JavaScript port of TidalCycles. Write code, run it, and it makes sound immediately. Change the code and the sound changes with it, live.

You don't need a programming background. If BPM, note names and chords already mean something to you, this will feel familiar — what you're writing is closer to DAW parameters than to software.

02 Make a sound in one minute

  1. Open strudel.cc in a browser
  2. Type this into the editor in the middle (clear whatever's already there)
  3. Press Ctrl + Enter (Mac: opt + Enter) to run it
  4. If you hear sound, that's it. Edit the code and hit Ctrl + Enter again — it switches instantly
$: note("c e g").s("sine")

Ctrl + . (period) stops it. If you get no sound, check the speaker icon on the browser tab first.

03 The core ideas, briefly

For depth, go to the function reference (REF) or the official strudel.cc/learn/getting-started. Here are four topics, one snippet each.

03-a Mini-notation — writing rhythm

Rhythm lives inside the quotes. Space-separated events are spread evenly across the cycle. Square brackets [] nest events to pack them tighter; angle brackets <> alternate one per cycle.

$: note("c d e f").s("sine")
// → c d e f are evenly spaced across one cycle

$: note("c [d e] f").s("sine")
// → d and e are packed into the nested [d e] step

$: note("<c e> g").s("sine")
// → cycle 1 plays c g, cycle 2 plays e g, alternating

03-b Choosing and shaping sound

note() sets the pitch, s() sets the sound. For waveforms you have sine / sawtooth / square / triangle and others.

$: note("c3 e3 g3").s("sawtooth")
// Play a C major chord with a sawtooth synth

03-c Effects — carving and placing the sound

Effects are just functions chained on. lpf() is a low-pass filter — lower the number and the sound gets rounder. room() is reverb, from 0 to 1.

$: note("c3 e3 g3").s("sawtooth").lpf(600).room(0.4)
// Apply a filter and add reverb

03-d Transforming patterns — faster, slower, backwards

fast() speeds it up, slow() slows it down, rev() plays the pattern backwards. Stack these and variations appear fast.

$: note("c d e f").s("sine").fast(2)
// Play at double speed
