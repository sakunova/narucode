はじめてガイド / 日本語

Strudelをはじめよう

ブラウザだけで動くライブコーディング環境「Strudel」を、 かいつまんで日本語で解説します。インストール不要・無料。

01 Strudelとは

Strudel（ストルーデル）は、ブラウザだけで動く音楽プログラミング環境です。strudel.cc を開けばすぐ使えます。ダウンロード不要・無料。

TidalCycles の JavaScript 版として開発が続いています。コードを書いて実行すると、その場で音が鳴ります。コードを変えると音もリアルタイムで変わります。

「プログラミングをやったことがない」でも、音楽の言葉（BPM・音名・コード）が通じる人なら違和感なく始められます。書くのはDTMのパラメータに近い感覚です。

02 1分で音を鳴らす

  1. ブラウザで strudel.cc を開く
  2. 画面中央のエディタに以下を入力（既存コードは全部消してOK）
  3. Ctrl + Enter（Mac: opt + Enter）で実行
  4. 音が鳴ったら成功。コードを変えて再度 Ctrl + Enter で即座に切り替わる
$: note("c e g").s("sine")

止めるときは Ctrl + .（ピリオド）。音が出ない場合はブラウザのスピーカーアイコンを確認してください。

03 基本概念（かいつまみ）

深掘りは 関数リファレンス（REF） と公式 strudel.cc/learn/getting-started へ。ここでは4つのトピックを1コードずつ紹介します。

03-a ミニノーテーション — リズムを書く

クォートの中の文字列でリズムを表現します。スペース区切りで均等に配置。角括弧 [] で入れ子にすると密になり、山括弧 <> でサイクルごとに交互に切り替わります。

$: note("c d e f").s("sine")
// → 1サイクルに c d e f が均等に並ぶ

$: note("c [d e] f").s("sine")
// → [d e] の中に2音が詰まり密になる

$: note("<c e> g").s("sine")
// → 1サイクル目は c g、2サイクル目は e g と交互

03-b 音を選ぶ・作る

note() でピッチを指定し、s() で波形（音色）を指定します。波形は sine / sawtooth / square / triangle などが使えます。

$: note("c3 e3 g3").s("sawtooth")
// ノコギリ波シンセでCメジャーコードを鳴らす

03-c エフェクト — 音を削る・空間に置く

関数をチェーンでつなぐだけでエフェクトが掛かります。lpf() はローパスフィルター（数値を下げると音が丸くなる）、room() はリバーブ（0〜1）です。

$: note("c3 e3 g3").s("sawtooth").lpf(600).room(0.4)
// フィルターをかけてリバーブを足す

03-d パターン変形 — 速さを変える・逆にする

fast() で速く、slow() で遅く。rev() でパターンを逆順に再生します。これらを組み合わせるとすぐにバリエーションが生まれます。

$: note("c d e f").s("sine").fast(2)
// 2倍速で再生
